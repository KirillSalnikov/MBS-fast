# Согласование соседних углов в некогерентном fullauto

## Актуальное исправление v3

Версия v2 уменьшила шум, но её критерий оказался недостаточным. Для рассчитанного
столбика 112,2 × 73,7 мкм, 160–170°, он допускал 0,002317 в разности M22/M11,
когда сам элемент в конце конуса был около −0,025. Новая политика
incoherent-component-shape-noise-v3 заменяет формулу v2, приведённую ниже:

    A_j = max(ε, max_рассчитанные_углы |mean(M_j)/mean(M11)|)
    angular_fraction = min(interpolation_tolerance, ε/4)
    allowance_j = min(interpolation_tolerance, angular_fraction * A_j)

Таким образом на угловой шум выделяется не более четверти допуска относительно
амплитуды элемента в конусе. Более строгий явно заданный допуск интерполяции
соблюдается. Для ε = 0,04 минимальный предел при стандартной интерполяции равен
0,0004, вместо 0,0016 в v2. У фактически рассчитанного M22 столбика 112,2 мкм
предел стал 0,0005793. Это не требование относительной точности в каждом нуле.

Дополнительно проверяется шум изгиба на тройке опорных углов a < b < c:

    w = (θ_b − θ_a) / (θ_c − θ_a)
    d_s = [M_j,s(b) − (1−w) M_j,s(a) − w M_j,s(c)] / min(mean M11(a,b,c))
    noise95 = t(7; 0,975) * std(d_s) / sqrt(8)

Для отношений используется та же комбинация линеаризованных величин u_s,
определённых ниже. Среднее d_s вычитается при вычислении стандартного отклонения.
Ограничивается неопределённость изгиба, а не его средняя величина: физические
пики и минимумы не выпрямляются. Веса используют реальные θ на неравномерной сетке.

Тройки берутся с шагом один и два по списку опорных углов. Второй шаг выявляет
шум на масштабе четырёх соседних интервалов, который отдельные пары могут
не обнаружить. Число проверок и размер диагностик линейны по числу опорных углов.
Предел шума изгиба равен allowance_j. Это не строгая оценка производной.

Уточнение использует ковариацию уровней с полной проверяемой разностью.
На значимых уровнях меньшие выборки догоняют максимальную внутри пары/тройки,
не более чем вчетверо за шаг. Если выравнивать нечего, вся группа удваивает
выборку определяющего уровня. Максимум не распространяется на весь конус.
Ограничитель длительности раунда сохраняет тройку целиком, включая восстановление.

Новый файл angular_shape.csv содержит три угла, шаг по опорам, элемент,
средний изгиб, его шум, допуск и старые/предлагаемые N. В angular_sampling.json
и fullauto_status.json добавлены angular_shape_checked_stencils,
angular_shape_failed_stencils и angular_shape_max_allowance_ratio.
Общий angular_sampling_pass требует прохождения пар и троек;
angular_sampling_failed_pairs по-прежнему считает только пары.

В тестах сохранены все восемь реализаций принятого v2 результата 112,2 мкм.
Это регрессия ложной для новой политики остановки, без нового физического
расчёта и без сглаживания. Объединённая матрица в этом тесте представлена
одним уровнем только для проверки критерия; распределение работы по физическим
уровням проверяется отдельно. Прохождение v3 не даёт одновременной строгой
гарантии на все углы и не заменяет независимый физический эталон.

## Предыдущие версии и общие определения

Политика `incoherent-component-shape-noise-v3` действует для физической оптики
с `--incoherent`, когда используется локальный подбор числа ориентаций
(`--fullauto-local-orientations auto` или `on`). Нового флага включения не нужно.
При `off`, в когерентном режиме и в геометрической оптике эта проверка не действует.

## Что исправлено

Опорный угол — угол, матрица которого используется для построения интерполяции.
Раньше соседние опорные углы могли иметь сильно различающиеся числа ориентаций.
Проверка интерполяции использовала свою общую выборку, а опубликованная матрица —
производственные выборки разной длины. Поэтому небольшая ошибка интерполяции
сама по себе не исключала случайных провалов между соседними опорными точками.

На сохранённом некогерентном расчёте столбика 562,3 × 165 мкм, λ = 0,532 мкм,
m = 1,3116, φ = 32 обнаружен следующий участок:

| θ, градусы | N при n = 8 | N для поправки n = 10 − n = 8 | N для поправки n = 12 − n = 10 | M11 |
|---|---:|---:|---:|---:|
| 168,4497887553 | 65 536 | 8 192 | 2 048 | 1385,5082 |
| 168,4660383490 | 32 768 | 512 | 512 | 1243,0384 |
| 168,4790380240 | 131 072 | 8 192 | 2 048 | 1448,5685 |

N — число ориентаций **в каждом из восьми независимых наборов**. n — ограничение
числа внутренних отражений. Поправка уровня — парная разность результатов
с двумя значениями n; итоговая матрица складывается из базового уровня и поправок.
Это промежуточные данные, а не сошедшийся эталон.

Оценка шума разности соседних M11 составила 5,524% и 7,801% от M11.
Максимум по всем 16 элементам — 7,789% и 7,983%, в обоих случаях у M33.
Новый критерий обнаруживает обе пары без изменения сохранённых матриц.

## Проверяемая величина

Для каждой соседней пары опорных углов a, b и каждого элемента j берутся
восемь уже рассчитанных реализаций. Для ненормированных элементов:

```
d_s = (M_j,s(b) − M_j,s(a)) / min(mean(M11(a)), mean(M11(b)))
noise95 = t(7; 0,975) · std(d_s) / sqrt(8)
```

`s` — номер независимого набора; `std` — выборочное стандартное отклонение
с делителем 7; `t(7; 0,975) ≈ 2,3646` — коэффициент распределения Стьюдента.
При расчёте отклонения вычитается среднее `d_s`. Поэтому реальный наклон,
узкий пик или резкая детерминированная структура сами по себе не запрещаются.

Для отношений `M_j/M11` дополнительно проверяется шум разности линеаризованных
оценок отношений. Коэффициенты линеаризации фиксируются по средним матрицам:

```
r(a) = mean(M_j(a)) / mean(M11(a))
u_s(a) = (M_j,s(a) − r(a) · M11,s(a)) / mean(M11(a))
d_s = u_s(b) − u_s(a)
```

Если обычная проверка отношения методом Фиеллера не разрешает знаменатель,
линеаризованная оценка не может дать положительное решение. Проверяются все
16 ненормированных элементов и 15 нетривиальных отношений, если проверка
отношений включена. M11/M11 тождественно равно единице.

В версии v1 допуск этой проверки был равен **ε/4** для всех элементов.
Это пропускало видимый шум слабого M22: 1% M11 может составлять десятки процентов
самого M22. В v2 для каждого элемента j вычисляются:

```
A_j = max(ε, max_рассчитанные_углы |mean(M_j)/mean(M11)|)
allowance_j = min(ε/4, ε * A_j)
```

`A_j` — амплитудный масштаб элемента на рассчитанной части конуса. Нижний
предел ε исключает деление на ноль и бесконечное уточнение из-за перехода
элемента через ноль. Это практический смешанный абсолютный/относительный
критерий углового шума, **не** требование относительной ошибки ε в каждом нуле.
Масштаб выбирается по текущим средним, но не используется как вес матрицы.
Если допуск интерполяции задан иначе, вместо ε/4 используется его действующее
значение; прежняя проверка никогда не ослабляется.

При `--fullauto .04` M11 сохраняет предел 1%, а элемент с амплитудой
`max |M22/M11| = 0,1` получает предел 0,004 — 0,4% M11 для сырой разности
и 0,004 абсолютной величины для разности отношений. Минимальный предел
равен 0,0016. Проверяются обе величины, если отношения включены.
Определяющим становится элемент с наибольшим `noise95/allowance_j`,
а не обязательно с наибольшим шумом в единицах M11.
Это дополнительный критерий шума,
а не добавка к сумме ошибок и не повторный независимый аудит.
`--fullauto-final-checks off` его не отключает.

Оценки Стьюдента и линеаризации являются статистическими приближениями.
Они не дают одновременной строгой гарантии на все углы, производные и все
элементы. Остальные проверки точности, интерполяции и физических параметров
сохраняются.

## Как назначается уточнение

1. Для не прошедшей пары определяется элемент с наибольшим отношением шума к своему допуску.
2. По ковариации с полной разностью выделяются уровни отражений, которые
   вносят положительный вклад в её разброс. Рассматриваются уровни с вкладом
   не меньше 1/8 наибольшего положительного вклада.
3. На этих уровнях меньшая выборка увеличивается в сторону большей.
   За один шаг её рост ограничен четырьмя разами и `--max-orientations`.
4. Если такого увеличения нет, обе точки удваивают выборку наиболее
   значимого уровня. Все предложения вычисляются по исходным размерам
   выборок: максимум не распространяется цепочкой на весь конус.
5. Пара передаётся ограничителю длительности раунда как совместная группа.
   Дальнейший расчёт использует сохранённые блоки и достраивает недостающие
   префиксы последовательностей Sobol. Префикс — первые N ориентаций
   соответствующего независимого набора.

Совпадение длин выборок способствует взаимному сокращению случайных
колебаний. Оно не означает автоматического принятия: шум вычисляется снова
после уточнения. Если достигнут предел N, не прошедшая проверка остаётся
не пройденной. Матрицы не фильтруются, не подгоняются под кривую и не заменяются
контрольным расчётом с меньшим N.

Сам критерий работает с уже вычисленными матрицами, без новой трассировки.
Уточнение не прошедших пар требует дополнительной работы. Ускорение всей
крупной серии этой правкой пока не измерено.

## Диагностика и восстановление

- `angular_sampling.json` — результат проверки, допуск, максимум шума,
  число проверенных и не прошедших пар, амплитудные масштабы и допуски всех
  16 элементов. `angular_sampling_max_allowance_ratio` должен быть ≤ 1.
  Старые поля `angular_sampling_noise95` и `angular_sampling_tolerance`
  показывают абсолютный максимум и общий потолок; их сравнения теперь
  недостаточно для принятия слабых элементов.
- `angular_sampling.csv` — соседние углы, определяющий элемент, текущие N
  и объединённое предложение следующего N по уровням. Ограничитель времени
  может отложить часть предложения; фактически назначенная выборка сохраняется
  в обычном чекпоинте и журнале распределения.
  Столбец `allowance` содержит допуск определяющего элемента данной пары.
- Такие же файлы находятся в папке соответствующего `round_snapshots`.
- `fullauto_status.json` содержит `angular_sampling_checked`,
  `angular_sampling_round`, `angular_sampling_pass`,
  `angular_sampling_noise95`, `angular_sampling_tolerance`,
  `angular_sampling_failed_pairs`. Номер раунда указывает, к какой оценке
  относятся эти значения.
- `intermediate_current.json`, `round_decision` и `precision_contract.json`
  тоже содержат результат нового критерия.

При восстановлении незавершённого старого расчёта сбрасывается только
серия успешных проверок по старому критерию. Блоки, матрицы и числа ориентаций
сохраняются. Сохранённые пары используются как подсказка планировщику;
точность пересчитывается по текущим данным. Уже завершённые старые результаты
остаются неизменными и не объявляются задним числом прошедшими новую проверку.

Регрессионная проверка с реальными восемью реализациями:

```bash
bash tests/run_fullauto_angular_sampling_tests.sh /tmp/mbs-angular-check
```

Исходные числа, происхождение и хеши файлов: `tests/data/fullauto_angular_sampling_562.*`.

## Проверка на завершённых малых столбиках, 3 ноября 2026

Восстановлены все 16 элементов из восьми сохранённых реализаций для семи
некогерентных конусов: 100; 112,2; 141,3 мкм при 150–160° и 100; 112,2;
125,9; 141,3 мкм при 160–170°. Проверенные значения совпали с опубликованными
DAT с расхождением меньше 10⁻⁶ M11. Это проверка воспроизведения данных,
не независимое подтверждение физической точности.

На выбранных проблемных участках все семь конусов проходили v1, но провалили
проверку слабых элементов v2. Реальные данные и происхождение сохранены в
`tests/data/fullauto_angular_sampling_small.*` и воспроизводятся тем же тестом.
Проверяются сохранность матриц, ограниченный рост N, восстановление приоритетов,
нулевые переходы, резкая детерминированная структура и все 16 элементов.

Общие ориентации помогают не везде одинаково. Например, для столбика 141,3 мкм
в тройке 163,1860465; 163,2325581; 163,2558140° статистическая оценка шума
трёхточечной разности M11 снизилась с 0,677% до 0,080% M11 на доступной общей
выборке [2048, 256, 256] по трём уровням. Это **не** означает, что короткая
выборка точнее по абсолютному M11 или что её можно подставить вместо результата.
Снижение шума разностей не подтверждает отсутствие общего смещения.

Новая проверка не исправляет готовый DAT задним числом. Для доуточнения нужен
дочерний расчёт с сохранёнными блоками (`--fullauto-refine-window`); обычная
загрузка завершённого чекпоинта сохраняет результат и сообщает, что новый
критерий не применялся. Простое сглаживание графика не заменяет доуточнение.
Затраты на него и скорость всей серии с v2 пока не измерены. Условие ε по
M11 и абсолютным отношениям в основном контракте точности сохраняется;
v2 не объявляет все слабые значения точными до ε относительно самих себя.
