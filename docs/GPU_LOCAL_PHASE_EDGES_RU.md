# FP32 + double-single: точная фаза на отдельных рёбрах

Эксперимент от 10 ноября 2026. Проверен на RTX 5080 (sm_120).
Производственные процессы и бинарники не заменялись.

В компактном дифракционном ядре короткий фазовый шаг ребра (меньше 0,125)
раньше включал точный double-single полином для всех вершин полигона.
Эксперимент отмечает оба конца каждого такого ребра. Остальные вершины
используют существующий быстрый FP32-полином с double-single приведением
фазы. Общие вершины имеют одно значение во всех рёбрах. Порог, фазы,
сингулярная поправка, моменты малой фазы и критерии fullauto не изменены.
Это не глобальный fast-math и не FP32-вычисление исходной большой фазы.

## Сборка

```bash
make -C gpu GPU_PRECISION=fp32 GPU_PHASE_TRIG=double_single \
  GPU_PHASE_EDGES=local GPU_FAST_MATH=0 GPU_ARCH=120
```

Для RTX 3080 Ti архитектура — `GPU_ARCH=86`; на ней этот эксперимент
ещё не проверен. Пути CUDA и host-компилятор задаются обычными параметрами
проекта. Экспериментальный бинарник и каталог объектов получают отдельный
суффикс `_ds_local_edges`; при явном OBJDIR/TARGET выбирайте отдельные пути.
Режим разрешён только с `GPU_PHASE_TRIG=double_single`.
По умолчанию `GPU_PHASE_EDGES=polygon`: прежний алгоритм.
Содержимое ветвей после препроцессора сверено со старой и испытанной сборкой.

## Проверка точности

Bullet D=L/2; λ=0,532 мкм; Re(m)=1,3116; n=6; 64 одинаковые
Sobol-ориентации, seed=11, Haar alpha, symmetry=1×1, φ=8,
257 углов, cutoff off. Для поглощения Im(m)=0,00042407.
Проверены все 16 элементов и отношения Mij/M11.

| Размер и диапазон | Изменение против старой GPU, % M11 | Отличие новой GPU от CPU FP64, % M11 |
|---|---:|---:|
| 5 мкм, 0–180° | 0,00000933 | 0,002153 |
| 20 мкм, 0–180° | 0,00001039 | 0,001253 |
| 1000 мкм, 0–1° | 0,00000304 | 0,003422 |
| 1000 мкм, 170–180° | 0,00006261 | 0,080069 |
| 1000 мкм, поглощение, 170–180° | 0,00001242 | 0,053634 |
| 20 мкм, некогерентный, 150–170° | 0,00000048 | 0,001631 |

Максимальное изменение нормированного отношения против прежней GPU:
2,01×10⁻⁷ (абсолютное). Это сравнение арифметики на фиксированной
выборке, не доказательство сходимости ориентационного среднего.
CPU FP64 — отдельная реализация дифракции, а не аналитический эталон.
Для произвольных форм, других seed и больших выборок нужна дополнительная
проверка перед включением по умолчанию.

## Скорость и ограничения

RTX 5080 одновременно выполняла производственный расчёт. Отношения полных
времён baseline/candidate колебались от 0,21 до 3,22. Эти числа нельзя
считать измеренным ускорением: нагрузка и ожидание GPU менялись.
Число регистров/размер стека компактных ядер по cuobjdump не изменились.
Нужен замер на свободной карте; по умолчанию эксперимент не включён.
