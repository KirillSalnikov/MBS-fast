\section{Fullauto: practical and mathematical
guide}\label{fullauto-practical-and-mathematical-guide}

This guide describes the integrated code prepared for MBS-fast 2.0. For
the extended Russian explanation and worked parameter definitions, see
\url{FULLAUTO_RU.md} or \href{FULLAUTO_ADAPTIVE_RU.html}{HTML}.

\subsection{Start with the physical
inputs}\label{start-with-the-physical-inputs}

\noindent\begin{minipage}{\linewidth}
\begin{verbatim}
make -C cpu -j2
cpu/bin/mbs_po_mpi --method po --backend cpu \
  --particle 1 5 2 --ri 1.3116 0 --wavelength-um 0.532 \
  --fullauto 0.02 --output results/column_5um
\end{verbatim}
\end{minipage}

The type-1 column has axial length 5 and basal diameter 2, in the same
units as the wavelength. \texttt{0.02} means 2\%. For a file particle,
replace \texttt{-\/-particle\ 1\ 5\ 2} with
\texttt{-\/-particle-file\ examples/cube.particle\ -\/-resize-dmax-um\ 5}.
Dmax is the maximum vertex separation, not a volume-equivalent diameter.

No Python controller or hand-written orientation file is required. Do
not add an explicit Sobol selector to make fullauto use Sobol. Run one
controller per output directory, without a multi-rank MPI launch.

For CUDA, build \texttt{make\ -C\ gpu\ fp64\ GPU\_ARCH=70\ -j2} and use
\texttt{gpu/bin/mbs\_po\_gpu\_double\ -\/-backend\ cuda} instead of the
CPU executable/backend. Architectures 70, 86 and 89 correspond to V100,
RTX 3080 Ti and RTX 4090. Add \texttt{-\/-fullauto-theta-range\ 0\ 25}
for the forward cone or \texttt{-\/-fullauto-theta-range\ 170\ 180} for
the backward cone. The default GPU list is \texttt{0};
\texttt{-\/-fullauto-gpus\ 0,1} shares work across two visible devices.
Indices are relative to \nolinkurl{CUDA_VISIBLE_DEVICES}.

A fullauto controller handles one size. Legacy multisize flags are a
separate workflow. Give independent sizes different output directories
and GPU resources.

\subsection{Controller sequence}\label{controller-sequence}

The controller validates inputs and restores compatible saved work,
chooses initial budgets and the requested output grid, and selects
reflection depth unless fixed. CUDA uses a bounded kernel/phi pilot
before the depth comparison; complete production tuning follows at the
selected depth.

Next it verifies supported symmetries, fits control coefficients on
training scrambles and validates them on different scrambles. It chooses
phi and execution settings from measured cost and variance. Unsupported
controls are disabled while the full PO calculation remains available.

Production evaluates support/check angles, depth levels and eight
replicas. Completed blocks are durable and reused. Each round estimates
statistical uncertainty, matched interpolation residuals and prefix
stability. The next round increases samples or angular support where
needed. After working criteria pass, enabled independent and physical
audits run. An unresolved limit or failed audit is not a converged
result.

\subsection{Sobol and the orientation
measure}\label{sobol-and-the-orientation-measure}

An orientation is \(R=R_z(\alpha)R_y(\beta)R_z(\gamma)\). The isotropic
average is

\[\langle M\rangle=\frac1{8\pi^2}\int_0^{2\pi}\!d\alpha
\int_0^\pi\!\sin\beta\,d\beta\int_0^{2\pi}\!M(R,\theta)\,d\gamma.\]

This is Haar measure on SO(3), the group of rotations in three
dimensions. For full-domain Sobol points \((u,v,w)\), use
\(\cos\beta=1-2u\), \(\gamma=2\pi v\) and \(\alpha=2\pi w\). Uniform
beta without the sine weight is incorrect. Verified symmetry can reduce
the domain with the proper reconstruction.

Nested Owen scrambling randomizes a Sobol sequence while retaining its
space-filling structure. Eight independent seeds give eight complete
estimates, not eight independent points. Samples within a replica are
not ordinary IID Monte Carlo. Power-of-two prefixes allow incremental
refinement and reuse. \nolinkurl{-\/-sobol-offset} continues a native
worker prefix without discarding prior work.

Let \(Y_r\) be the complete level/control/cutoff estimate of replica
\(r\):

\[\bar Y=\tfrac18\sum_rY_r,\qquad
s^2=\tfrac17\sum_r(Y_r-\bar Y)^2,\qquad
h_{95}=t_{0.975,7}s/\sqrt8.\]

The Student-t factor is approximately 2.365. The combined replica
preserves covariances between coupled differences. Normalized ratios
account for numerator/denominator covariance and unresolved
denominators; halved prefixes supply an additional stability check.

Sobol is the current production default and a practical choice for the
measured PO campaigns. Its extensible prefixes and coupled differences
suit irregular integrands and local refinement. This does not establish
a universal advantage over Lebedev or Wigner rules on every shape or
smooth integrand.

\subsubsection{Why both alpha and phi
exist}\label{why-both-alpha-and-phi-exist}

Alpha rotates the particle around the illumination axis; phi changes the
observation azimuth. With full Haar alpha, extra phi samples retain the
same expectation and can reduce variance using the same traced beams.
Polarized quantities also require the correct Stokes-basis rotation.
More phi can be cheaper than retracing more orientations, so the
controller chooses their cost tradeoff. A sixfold body symmetry does not
divide laboratory alpha by six.

Fullauto supplies \nolinkurl{-\/-haar-alpha} in PO worker recipes.
\texttt{-\/-phi-points\ 4} fixes four observation azimuths. For a
starting count of 32768 per seed use
\texttt{-\/-fullauto-initial\ 32768}, not a competing manual orientation
selector.

\subsection{Analytic work and numerical
work}\label{analytic-work-and-numerical-work}

The diffraction of a planar polygonal beam contains
\(F(\mathbf q)=\int_A e^{i\mathbf q\cdot\mathbf x}\,dA\).
Constant-amplitude polygon integration reduces to edge expressions, with
stable limits/moments near zero phase and small denominators. This is
analytic diffraction at one orientation, not a closed orientation
average of the entire particle.

An analytic control \(C\) with known mean \(\mu_C\) uses

\[\widehat M=\overline{M-bC}+b\mu_C.\]

The coefficient \(b\) is fitted independently. Internal paths, occlusion
and interference missing from \(C\) remain in the full numerical
residual. Averaging Fresnel coefficients and substituting them at every
reflection would not be this estimator. In coherent PO, amplitudes are
summed before forming Mueller matrices. Incoherent PO sums beam
intensities and uses a different path.

Facet/self-reflection and shadow components provide physical control
means. For incidence cosine \(\mu\), the Fresnel coefficients
\(r_s,r_p\) give \(R(\mu)=(|r_s|^2+|r_p|^2)/2\). A Legendre moment is,
for example, \(c_\ell=(2\ell+1)\int_0^1R(\mu)P_\ell(\mu)d\mu/2\); actual
kernels also include projection/geometric weights. Legendre addition and
plane-wave expansions integrate angular phase factors using spherical
Bessel functions. Smooth Fresnel quadrature, radial tables and parts of
the edge preparation remain numerical. Means are shared across angles
and cached for compatible inputs.

\nolinkurl{-\/-analytic-facet-average} requests the facet control.
\texttt{-\/-analytic-shadow-control\ circular} uses a circular-aperture
control with a geometry-derived area, with model differences retained in
the residual. \texttt{-\/-analytic-mean-cache\ FILE} specifies its
persistent mean cache. Fullauto can choose these automatically; forcing
a control is not a guarantee that it reduces variance or setup time.
Polarization controls undergo separate validation; analytic M11 control
does not analytically solve all 16 elements.

\subsection{Depth and cutoff
differences}\label{depth-and-cutoff-differences}

For depth levels \(n_0<\cdots<n_L\),

\[E[M_{n_L}]=E[M_{n_0}]+\sum_{\ell=1}^LE[M_{n_\ell}-M_{n_{\ell-1}}].\]

Both terms of a difference use identical orientations. Where supported,
a trace produces both depths. Each term is a complete coherent Mueller
estimate at its own depth, so interference terms are retained. A
low-variance correction needs fewer samples than the expensive full
solution.

Default coherent PO pruning uses
\(\widehat M=\overline B_N+\overline{(O-B)}_m\), where \(B\) is balanced
and \(O\) is uncut. The physical target remains uncut, with cutoff
correction uncertainty included in the complete replicas. Explicit
\texttt{-\/-cutoff-profile\ balanced} fixes a preset and bypasses this
automatic policy; it is not an alias for the corrected estimator.
\texttt{-\/-cutoff-profile\ off} fixes no pruning.

\subsection{Angular interpolation and
acceptance}\label{angular-interpolation-and-acceptance}

The output grid, interpolation supports and guard angles are distinct.
For fixed supports local cubic interpolation \(I\) is linear in their
matrix values. The check is \(\Delta=M(\theta)-I[M_{support}](\theta)\)
on matched orientations. A separate checkpointed residual budget
prevents a difficult neighbor's very large production count from
automatically inflating this check. Both sides use the same phi rule
even if production phi varies by angle.

At a guard, confirmed residual structure can add support; a noisy
residual first grows its coupled sample. Newly inserted production
angles use ordinary startup budgets. Complete cached eight-seed prefixes
remain reusable. The round scheduler uses measured cost to limit new
work; its 1800 worker-second per-GPU target is advisory, not a
wall-clock promise.

The first production round also uses that cost target. The empirical
initial count is an upper proposal: before reading production matrix
values, the controller chooses a power-of-two base count from measured
timings, starting at 512 when timings are missing. Complete cached
eight-seed prefixes and the correction minima are retained.
\nolinkurl{initial_production_work.json} records the proposal, selected
count and forecast. Explicit \nolinkurl{-\/-fullauto-initial}, a loaded
adaptive configuration and \texttt{-\/-fullauto-local\ off} keep their
requested start. Later rounds use the ordinary error-driven refinement
and unchanged acceptance tests. A first-round estimate can therefore
appear before the empirical count has been reached; it is not a
convergence declaration.

All 16 errors are scaled by local M11, not by a potentially zero Mij.
Ratio checks use absolute errors in Mij/M11. At each component/angle,
statistical and interpolation terms plus fixed reserves must fit EPS;
take the maximum \textbf{after} this componentwise sum. At unchecked
output angles the full EPS/4 interpolation allowance is retained.
Independent and physical checks have their own recorded policies.

These are pointwise uncertainty estimates. They are not a global
simultaneous confidence bound, an error bound on PO versus Maxwell's
equations, or proof that every unsampled angular feature has been found.

\subsection{Results and recovery}\label{results-and-recovery}

A persistent worker that reports a recoverable RAM-budget failure is
retried once in a fresh process with exactly the same sampling. The
failed attempt's partial output is never committed, and its log is saved
as \texttt{stdout.memory-retry.log}. For the system RAM reserve guard,
the controller waits at most 60 seconds for the reserve to recover after
releasing that worker. It records \nolinkurl{resource_wait.json} and
memory-retry events. The reserve is not lowered. Continued pressure or
an unrelated numerical/CUDA failure stops the task and preserves
completed checkpoints for recovery.

Read \nolinkurl{fullauto_status.json} for convergence and selected
settings. \nolinkurl{intermediate_current.json} points to the last
published matrix snapshot. \nolinkurl{execution_progress.json} reports
active work, not a newly measured accuracy.
\nolinkurl{fullauto_history.jsonl} records parameter changes and execution
events.

\nolinkurl{mueller_fullauto.dat} contains the requested output grid. Guard
rows can contain interpolation even when a separate direct check exists.
Read \nolinkurl{point_type} and \nolinkurl{value_source} in
\nolinkurl{mueller_fullauto_annotated.csv}; use
\nolinkurl{mueller_evaluated.dat} for direct estimates. Empty error fields
mean unavailable, not zero. \nolinkurl{parameters_accuracy.csv} and
\nolinkurl{interpolation_orientation_budget.csv} in each snapshot
distinguish production and residual sample budgets.

Resume the exact command with the same binary and output directory. Keep
the whole directory, including \nolinkurl{jobs/}, configuration, source
manifests and checkpoints. An incomplete block can repeat; complete
blocks are reused. Schema 6 stores both budgets and residual phi; older
checkpoint parsing does not by itself prove cross-binary numerical
compatibility.

A new binary requires an exact tested compatibility receipt before
\texttt{-\/-fullauto-resume-compatible\ OLD\_BINARY} can be used. Do not
edit fingerprints. \texttt{-\/-fullauto-refine-window\ A\ B\ EPS}
requests a documented child-window refinement from a retained parent
recipe rather than silently changing its physics.

\texttt{scripts/run\_fullauto\_service.sh\ UNIT\ BINARY\ LOG\ {[}arguments...{]}}
installs and starts a user systemd service for process recovery.
Numerical decisions remain native. It is an optional launcher, not a
required Python audit.

\subsection{GO and other modes}\label{go-and-other-modes}

\noindent\begin{minipage}{\linewidth}
\begin{verbatim}
cpu/bin/mbs_po_mpi --method go --backend cpu \
  --particle 1 100 50 --ri 1.3116 0 --wavelength-um 0.532 \
  --fullauto 0.02 --output results/column_go
\end{verbatim}
\end{minipage}

GO analytically averages alpha and computes fixed finite solid-angle
bins. There is no PO cubic interpolation. Forward/backward delta
matrices are separate integrated masses in \nolinkurl{mueller_forward.dat}
and \nolinkurl{mueller_backward.dat}, not point values of a continuous
phase function. GO mirror defaults off; supported explicit reduction
reconstructs \((M+PMP)/2\), \(P=diag(1,1,-1,-1)\), for nonabsorbing
built-in types 1/10. See \href{GO_MIRROR.md}{GO mirror} and
\href{GO_BALANCED.md}{GO balanced}.

\href{EXTINCTION_ONLY.md}{Extinction-only} is a separate convex
CPU/Hammersley PO workflow without an angular grid. It does not supply
full coherent albedo.
