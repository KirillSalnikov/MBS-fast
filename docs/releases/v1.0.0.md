# MBS-fast v1.0.0

First versioned production release of the CPU and CUDA physical-optics and
geometrical-optics solver.

## Highlights

- FP64 is the default CUDA reference profile; explicit FP32/FP64 and
  precise/fast-math build profiles use isolated object directories.
- Symmetry-reduced SO(3) orientation averaging supports mirror validation,
  diffraction-driven angular grids, adaptive convergence, restartable
  checkpoints, and multi-GPU theta-group scheduling.
- CUDA direct diffraction uses cached beam data, FP64 critical phases, stable
  small-phase polygon moments, stable near-singular edge limits, and an
  optimized phase hot path.
- Non-convex tracing uses double-precision geometry predicates, validated
  closed surfaces, deterministic facet ordering, forward-depth clipping, and
  area-conserving parent/child beam partitioning.
- Forward and backward poles use stable polarization bases and explicit
  Mueller limits. Coherent ray-path summation is audited and the undefined
  cross-orientation coherence option is disabled.
- Particle files can round-trip per-facet visibility through the
  `.visibility` sidecar.
- Runtime logs record build precision, CUDA architecture, resource use, and
  active result-affecting `MBS_*` environment variables.

## Validation

- CPU and CUDA FP64 weighted Mueller L2 difference: `9.555e-10`.
- CPU and CUDA FP32 weighted Mueller L2 difference: `3.472e-06`.
- Optimized FP64 diffraction kernel: approximately 8-10% faster in the tested
  saturated five-V100 environment, with an old/new Mueller L2 difference of
  about `4.93e-14`.
- Release gates cover command-line validation, SO(3) symmetry, pole stability,
  non-convex beam topology, forward-depth clipping, compiler warnings, CUDA
  build profiles, and CPU/CUDA numerical agreement.

## Reproducibility

Record the complete command and `--version` output with numerical results.
Use the precise FP64 binary for reference calculations and validate optional
FP32 or fast-math profiles on the same geometry, orientation grid, and cutoff
settings before production use.
