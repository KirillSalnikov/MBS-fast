# MBS-fast v1.0.1

This maintenance release removes obsolete root-level build wrappers and
architecture-specific build scripts. The supported build interface remains:

- `make -C cpu -j` for the MPI/OpenMP CPU binary;
- `make -C gpu -j` and the `fp32`, `fp64`, `fp32_fast`, and `fp64_fast`
  targets for CUDA binaries;
- `scripts/detect_arch_flags.sh` and
  `scripts/select_cuda_host_compiler.sh` for architecture and CUDA host
  compiler selection.

The regression suite now builds the canonical CPU target directly through
`cpu/Makefile`. The README now matches the supported build and release paths,
and obsolete one-off reports plus unreferenced generated figures were removed.
No physics, command-line, or numerical behavior changed from v1.0.0.
