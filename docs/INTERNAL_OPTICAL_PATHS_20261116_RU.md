# Пакетное восстановление внутренних оптических путей

При поглощении PO восстанавливает внутренний путь для трёх опорных точек
апертуры, чтобы получить его изменение по апертуре. Направления сегментов
и знаменатели пересечений одинаковы для этих точек. `ComputeInternalOpticalPaths3`
вычисляет их один раз на сегмент; проекции и сумма длин остаются отдельными
для каждой точки, в прежнем порядке. Выбор опорного треугольника не меняется.

Оптимизация включена по умолчанию. Для диагностического сравнения:

```bash
MBS_BATCH_INTERNAL_PATHS=0 ./mbs_po_gpu_float_ds <обычные параметры запуска>
```

Переменная читается один раз в процессе. Значение `0` включает прежнее
скалярное восстановление каждой точки; отсутствие переменной включает пакетный вариант. Число
отражений, cutoff, ориентации, допуск и формулы поглощения не меняются.
При нечисловой проекции пакет целиком пересчитывается скалярным способом.
При стандартном `--abs-points 1` четвёртая точка — центроид площади
апертуры — теперь восстанавливается в том же проходе. Её положение и
формула поглощения остаются прежними. Для `--abs-points 2`, `all` и других
многоточечных правил сохраняется прежний выбор точек.

Отключить только объединение центроидного пути, оставив пакет трёх опорных:

```bash
MBS_BATCH_ABSORPTION_CENTROID=0 ./mbs_po_gpu_float_ds <обычные параметры запуска>
```

Обе переменные читаются один раз в процессе. При
`MBS_BATCH_INTERNAL_PATHS=0` каждый путь вычисляется скалярно, включая
центроид. Это вычислительная оптимизация, а не приближение интеграла
поглощения.

## Первое изменение: три общих пути

Изолированный ABA на RTX 3080 Ti: полный coherent PO fullauto, произвольная
частица Dmax=15,85 мкм, λ=1,55 мкм, m=1,2906+0,00042407i, диапазон 0–180°,
допуск 4%, четыре выделенных CPU-ядра, одинаковые бюджеты и seeds.

| Вариант | Время, с | Средняя загрузка GPU |
|---|---:|---:|
| Исходный A | 215,134 | 28,92% |
| Пакетный B | 206,127 | 32,39% |
| Исходный A повторно | 214,138 | 33,33% |

Время сократилось примерно на 4% относительно среднего двух A. Это результат
одного полного ABA на указанной задаче, а не обещание для всех размеров.
Рост загрузки GPU относительно обоих контрольных прогонов не подтверждён;
цель загрузки не ниже 50% на всём fullauto не достигнута.

Все прогоны завершились в раунде 5: n=8, φ=8, уровни выборок
[2048,1024,1024] на seed, 150 вычисленных углов, ошибка 3,286%.
Максимальное отличие всех 16 элементов — 1,09·10⁻⁷ M11; отношений Mij/M11 —
1,48·10⁻⁷. Отличие интегральных реплик, нормированное на максимальное абсолютное
значение соответствующей характеристики, не более 2,99·10⁻⁷. Это сравнение
одинаковых оценок; угловой допуск fullauto не сертифицирует точность интегралов.

Локальный ABA самого восстановления трёх путей дал около 2,5×; этот выигрыш
нельзя переносить на весь расчёт. 330939 проверок совпали бит-в-бит. Ещё
564156 проверок включали n=18, невыпуклый трассировщик, поглощение и его
отсутствие, общий путь нормалей и NaN/Inf-входы: максимальное расхождение
4,78·10⁻¹⁶. ASan/UBSan прошли. Битовое равенство не обещается всем веткам.

84 CUDA-запроса проверили арбитрари, буллит и дроксталл в когерентном и
некогерентном режимах, парные глубины 6/4, разные seeds, размеры и cutoff.
Максимальные отличия матриц/отношений — 6,76·10⁻⁸, интегралов — 3,35·10⁻⁸.

## Второе изменение: центроид в общем проходе

На той же задаче полный ABA относительно уже ускоренного варианта 3+1:

| Вариант | Время, с | Средняя загрузка GPU |
|---|---:|---:|
| Три общих пути + отдельный центроид | 208,083 | 32,76% |
| Четыре общих пути | 198,121 | 34,96% |
| Вариант 3+1 повторно | 206,123 | 32,22% |

Сокращение времени — **4,3%** относительно среднего двух исходных прогонов.
Это один полный ABA на произвольной частице с поглощением, не универсальная
оценка. Загрузка ниже 50% сохраняется в 69,7% секундных замеров кандидата.
Параметры сходимости и количество рассчитанных углов совпали.
Все 16 элементов отличаются не более чем на 6,27·10⁻⁸ M11, отношения —
9,78·10⁻⁸, интегральные реплики в той же нормировке — 3,09·10⁻⁷.

Отдельный CPU-тест операции 3+1 против четырёх общих путей дал около 1,7×.
40 пар CPU-расчётов проверили четыре геометрии, оба режима когерентности,
поглощение и его отсутствие, многоточечные пробы и скалярный резервный путь:
матрицы и интегралы совпали побитно. 56 CUDA-запусков (14 сценариев × четыре
варианта) прошли порог 3·10⁻⁵ по матрицам, отношениям и интегралам;
максимальное различие в использованных нормировках — 6,46·10⁻⁷.
Регрессионный тест трёх и четырёх путей проверил 1 698 354 значения с побитным
совпадением на данной CPU-сборке; проверка четырёх путей с ASan/UBSan прошла.
Битовое равенство всех CUDA-редукций этим не обещается.

Данные ABA: `tests/centroid_optical_paths_fullauto_20261116.json`.
