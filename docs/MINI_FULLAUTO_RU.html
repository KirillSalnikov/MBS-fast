GO: --go и особенности

/home/kirill_epyc/mbs-fast/releases/fullauto-go-depth-20261013-r5-fp64/bin/mbs_po_gpu_double \
  --go --backend cpu --particle 1 199.5 98.3 --ri 1.3116 0 --wavelength-um 0.532 \
  --fullauto 0.01 --fullauto-initial 512 \
  --scattering-grid 0 180 1 180 \
  --fullauto-cpu-workers 4 --threads 16 --output /FULL/PATH/prism_GO

--go и --method go равнозначны. Запись -go с одним дефисом текущий строгий парсер не принимает; для команды используйте --go или --method go. GO работает на CPU, складывает энергии пучков, усредняет α аналитически и адаптирует β/γ-выборку и n. 4 процесса ×16 потоков подходят для 64-ядерного epyc; на 12-ядерном сервере начните с 3×4. GPU память для GO не используется.

GO требует полной равномерной сетки 0–180°, NPHI=1. 180 — число интервалов между центрами, 181 — число центров. EPS относится к средней матрице конечного углового интервала. Ширина интервала не подбирается автоматически; нужные строки вперёд/назад выбираются из полной матрицы. Видеокарты, PO-интерполяция, Haar-alpha и контроли граней в GO не применяются.

Отдельные интегральные полюса сохраняются в mueller_forward.dat и mueller_backward.dat, плотности конечных интервалов — в mueller_fullauto.dat. Полюс и плотность имеют разные единицы. Ненаблюдённый полюс помечается zero_observed_not_bounded. GO использует --trace-cutoff*, не --beam-cutoff*. Явный n сохраняется; без него работает поиск 6…18.

Какая точность проверяется

Пилот n сравнивает n и n+2 на одинаковых ориентациях; неопределённость разности учитывается. Шумный пилот может увеличить N. Глубина получает EPS/4. PO-интерполяция также получает EPS/4; GO интерполяции не имеет. Затем выполняются независимая проверка ориентаций и свежая проверка n. Если она не пройдена, автоматический n повышается и оцениватель строится заново. После n=18 без успеха — код 4. Это чувствительность к усечению и точечные статистические интервалы, а не доказательство бесконечной глубины или одновременная 95%-гарантия по всем углам.

Старт по измеренным данным и порядок поиска

Стандарт --fullauto-initial-model empirical привязывает старт к размеру, длине волны, диапазону θ, форме и допуску. Использованы 234 завершённые записи, после удаления повторов — 73 различные настройки когерентной PO. Большая стартовая выборка в старых запусках могла скрывать достаточность меньшего N; при обучении её корректировали по измеренной дисперсии, не более чем в 16 раз. Данные и коэффициенты: docs/data/FULLAUTO_INITIAL_EMPIRICAL_V1.json.

Определения: Ledge — максимальное ребро формы после масштабирования; λ — длина волны; ε — допуск --fullauto; I(условие) равно 1, если условие выполнено, иначе 0. controls означает включённую аналитическую контрольную модель; prism означает встроенную частицу --particle 1. N — число ориентаций на один seed одного уровня, не суммарное число всех трассировок.

s = 8.5128934 + 2.0264267 log₂(1+Ledge/(8λ)) + 0.6416260 I(θmax>90°)
+ 4.0403518 I(θmax−θmin>90°) + 0.8222766 I(controls выключены) − 2.7035215 I(prism отсутствует);
Nпрогноз = 2ˢ (0.01/ε)²; Nстарт = pow2ceil(max(512, Nпрогноз/16)).

pow2ceil округляет вверх до степени двойки. Старт ограничен max(512,max-orientations/4), чтобы осталось место для уточнений. Модель даёт только начальную стоимость: окончательный N выбирает проверка точности. При проверке на исключённых из обучения группах медианная ошибка прогноза составила фактор 2,57, 90-й процентиль — фактор 11,53. Это не гарантия N. Для GO и некогерентного режима используется отдельный ограниченный старт с учётом поглощения. Явные --fullauto-initial и adaptive-config имеют приоритет.

По умолчанию --fullauto-depth-pilot равен min(512,Nстарт). Этот пилот выбирает n независимо от большой производственной выборки. --fullauto-depth-order auto на CUDA сначала выбирает ядро и φ на дешёвом пилоте (до 64 ориентаций и 9 θ), затем сравнивает n и n+2; после выбора n заново обучает итоговую контрольную модель. На CPU стандарт — depth-first. Можно явно задать sampling-first или depth-first; с ручным --max-reflections эти настройки поиска глубины не применяются.

Старая оценка ξ/16 сохранена только как --fullauto-initial-model xi. ξ=0.69λ/Ledge — угловой масштаб в радианах. При Δ=ξ/16 произведение полных сеток β×γ растёт как (Ledge/λ)². Это геометрическая оценка старого суммирования, а не требуемое число Sobol после аналитического α и контрольной модели.
